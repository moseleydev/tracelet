# Code of Conduct

Tracelet adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short: be respectful, assume good intent, welcome newcomers, and keep discussion focused on the work. Harassment, personal attacks and discriminatory language are not tolerated in issues, pull requests, discussions or any other project space.
